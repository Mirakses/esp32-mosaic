# csi-node — живий CSI з ESP32-S3

Мінімальна прошивка без дисплея для будь-якої плати ESP32-S3. Плата
підключається до домашнього роутера як звичайний Wi-Fi-клієнт, пінгує його
100 разів на секунду й з кожної відповіді знімає CSI, тобто амплітуду
сигналу на 52 піднесучих Wi-Fi. Ці дані стрімляться на шлюз
(`gateway/orb_gateway.py`), а сторінка `http://<шлюз>:9000/viz` показує їх
наживо: «водоспад» каналу, рівень руху та стан «тихо / РУХ».

Перевірено збіркою для ESP32-S3-DevKitC-1 з модулем N16R8.

## Що потрібно

- Mac або ПК, Python 3.10+, [PlatformIO Core](https://platformio.org/install/cli)
- Плата ESP32-S3 і USB-C кабель **з передачею даних**
- Wi-Fi 2,4 ГГц (5 ГГц ESP32 не бачить)

## 1. Шлюз

```bash
cd gateway
pip3 install aiohttp pyyaml
python3 orb_gateway.py
```

Відкрий у браузері `http://localhost:9000/viz`. Щоб перевірити сторінку без
плати, запусти в іншому вікні терміналу `python3 csi_sim.py`: він імітує
кімнату, де кожні 10 секунд хтось ходить.

## 2. Прошивка

```bash
cd firmware/csi-node
cp include/config.example.h include/config.h
# відредагуй include/config.h: Wi-Fi, IP комп'ютера зі шлюзом, назва вузла
pio run -t upload
pio device monitor        # лог; вихід — Ctrl+C
```

IP Mac'а дізнаєшся командою `ipconfig getifaddr en0`.

На платі два USB-C. Прошивати можна через будь-який. Якщо порт не
знаходиться, затисни **BOOT**, натисни й відпусти **RST**, потім відпусти
**BOOT** і запусти прошивку ще раз.

Світлодіод на платі: червоний означає підключення до Wi-Fi, жовтий — Wi-Fi є,
а шлюзу немає, зелений — дані йдуть.

## Поради для якісного сигналу

- Став плату за 2–5 м від роутера так, щоб кімната була між ними.
- Не клади плату впритул до металу чи до самого роутера.
- Натисни «Калібрувати» на сторінці, коли в кімнаті нікого немає: поріг
  руху налаштується автоматично.
- Перемичка антени: на багатьох платах із роз'ємом IPEX за замовчуванням
  працює антена на платі. Зовнішня антена дає стабільніший сигнал, але для
  неї треба перепаяти резистор 0 Ом біля роз'єму. Без антени на роз'ємі
  перепаювати не можна.
